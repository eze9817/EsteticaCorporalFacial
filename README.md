Mi primer proyecto web desde cero. Decidi crear esta pagina para reflejar y acompañar el trabajo, la dedicacion y el oficio de mi madre con el fin de ayudarla a mostrar lo que hace con tanto esfuerzo.

-ESTETICA CORPORAL Y FACIAL-
este proyecto esta contruido con:
-HTML5: 5 paginas (index, sobre nosotros, estetica facial, estetica corporal y contacto)
-CSS compilado desde SASS
-Flexbox y CSS Grid, para la estructura
-Diseño reponsive, con Mobile First
-Git y GitHub, para el control de los commits(versiones)

organizacio:
scss/main - compilado sass
scss/base - tipografia y reset de css
scss/components - button y card
scss/layout - body, footer, header, nav y media queries
scss/utilities - variabls y mixins
